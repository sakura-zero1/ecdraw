# 10kV 配电网智能绘图平台 — 需求规格说明书

> 版本：v1.1
> 日期：2026-04-10
> 基于项目：ECDraw 电气元件编辑器（元件编辑器功能已更新）

---

## 1. 项目概述

### 1.1 项目背景

当前 ECDraw 是一个基于 Web 的电气元件编辑器，用户可以在固定画布上绘制单个电气元件的符号形状、定义引脚位置和元件内部的连通矩阵。现需要将其扩展为一个面向 10kV 配电网的**多人协作智能绘图平台**，支持从元件设计到图纸绘制、审核发布、分析查询的完整闭环。

### 1.2 项目目标

构建一个 B/S 架构的配电网绘图系统，具备以下核心能力：

- **元件编辑器**：设计和管理 10kV 配电网所需的电气元件符号
- **配网图编辑器**：在自由画布上拖放元件、连线，绘制完整的 10kV 配电网络线路图
- **AI 智能助手**：接入大语言模型（LLM），通过自然语言对话辅助绘图、查询和分析
- **审核发布流程**：编辑者提交、审核者审批、变更上线后查看者可见
- **高级分析功能**：停电模拟、潮流计算等配电网分析工具

### 1.3 目标用户

电力系统配电网运维、设计、管理人员，包括元件设计人员、配网图纸绘制人员、图纸审核人员、以及需要查阅图纸的运维人员。

## 3. 核心业务流程

### 3.1 审核闭环流程

这是系统的核心业务流程，确保图纸变更经过审核后才对外可见。

```
 配网图编辑者              审核者               查看者
     │                      │                    │
     │  编辑图纸（草稿）      │                    │
     │  ──────────────►      │                    │
     │  提交审核             │                    │
     │  ──────────────►  审核队列显示待审项         │
     │                      │                    │
     │                  审批决策 ─┐               │
     │                          │                │
     │               ┌── 通过 ──┘                │
     │               │                           │
     │               ▼                           │
     │          自动发布上线  ─────────────────► 查看已发布图纸
     │                                           │ 使用高级分析
     │               ┌── 驳回 ──┐                │
     │               │          │                │
     │          ◄────┘          │                │
     │  编辑者收到驳回原因        │                │
     │  修改后重新提交 ──────►   │                │
```

```
 元件编辑者              配网图编辑者
     │                      │
     │  在元件编辑器中        │
     │  设计元件符号          │
     │  （形状、引脚、        │

     │         │             │

     │                      │         │
     │                      │         ▼
     │                      │   保存图纸 → 提交审核
```

## 4. 功能需求

### 4.1 用户管理模块

#### 4.1.1 用户认证
- 用户通过用户名和密码登录系统
- 登录后获取访问令牌（Token），用于后续 API 鉴权
- 支持令牌自动刷新，避免频繁重新登录
- 退出登录清除令牌

#### 4.1.2 用户管理（管理员专用）
- 查看所有用户列表（用户名、角色、状态、创建时间）
- 新增用户（设置用户名、密码、角色）
- 编辑用户信息（修改角色、重置密码）
- 启用/禁用用户账号
- 查看操作审计日志

### 4.2 元件编辑器模块

> 此模块为现有 ECDraw 功能。当前版本已包含完整的元件编辑能力，后续仅需接入后端持久化。

#### 4.2.1 元件管理
- 新建电气元件，设置名称、分类、描述
- 编辑已有元件的属性（名称、分类、描述）
- 删除元件
- 复制元件（完整复制形状、引脚和连通矩阵，自动重命名）
- 按分类浏览元件列表（侧栏折叠/展开）
- 元件列表显示分类标签和名称

#### 4.2.2 形状绘制
- 在元件自定义尺寸的画布上（默认 1200×800）绘制基本图形：矩形、圆形、椭圆、线段
- 设置形状属性：填充色、边框色、边框粗细、透明度
- 选中形状后可精确编辑几何参数（X/Y/宽/高/CX/CY/R/RX/RY 等）
- 形状选择、拖拽移动
- 多选（选择模式 Ctrl+点击 / 其他模式 Alt+点击）和框选
- 多选形状对齐（左/右/上/下/水平居中/垂直居中对齐 + 横/纵向等距分布）
- 形状组合/解组（Ctrl+G / Shift+Ctrl+G），组合后联动移动
- 形状缩放手柄：矩形（四角 nw/ne/sw/se）、圆/椭圆（四方向 e/w/n/s）、线段（起止端 start/end）
- 复制形状（Ctrl+C / Ctrl+V 或 Ctrl+D，偏移 20px）
- 删除形状（Ctrl+X / Delete / Backspace）
- 撤销操作（Ctrl+Z，最多 50 步快照）

#### 4.2.3 引脚管理
- 添加引脚（默认类型为双向，名称自增数字）
- 删除引脚（同时清理相关连通矩阵条目）
- 自由拖拽定位引脚在画布上的位置
- 引脚多选（Ctrl/Shift+点击），多选后可对齐（同形状对齐工具）
- 引脚拖拽时自动吸附到形状边界点（10px 阈值，显示十字准星预览）
- 引脚类型：输入(蓝)、输出(橙)、双向(紫)、电源(黄)、接地(灰)
- 引脚选中时显示白色描边高亮

#### 4.2.4 连通矩阵
- 定义引脚之间的连接关系（闭合/断开/无连接），点击矩阵单元格循环切换
- 切换连接状态（闭合/断开），连线颜色实时变化（绿=闭合，橙=断开）
- 连线可见性切换（👁 显示 / 🚫 隐藏）
- 连接状态驱动形状属性变化：每个连接可关联多个形状，为每个形状设置闭合/断开状态下的属性覆盖（填充、描边、粗细、透明度、几何参数）
- 播放开断动画（所有连接同时切换状态并恢复）
- 关联形状时可一键高亮定位（选中+闪烁动画）

#### 4.2.5 分类体系
- 四类配网专用分类：电源点（powerPoint）、分合点（switchPoint）、衔接点（junctionPoint）、负荷点（loadPoint）
- 每个分类有预定义的 SVG 形状模板（电源点为十字符号、分合点为刀闸符号、衔接点为十字交叉+圆点、负荷点为矩形+引线）
- 新建元件时选择分类，可自定义名称（留空则使用分类名称）

#### 4.2.6 界面布局
- 左侧：元件列表（可折叠），显示分类标签和元件名称，支持复制元件
- 中央：SVG 画布，网格背景（20px 间距），顶部浮动绘图工具栏，底部浮动对齐工具栏（选中 2+ 个图形/引脚时显示）
- 右侧：属性面板（可折叠），标签页模式切换"元件属性"和"引脚管理"
- 顶部工具栏：新建元件、导出项目、导入项目

### 4.3 配网图编辑器模块

#### 4.3.1 图纸管理
- 新建图纸，设置名称、描述
- 保存图纸（自动生成新版本）
- 打开已有图纸（支持查看历史版本）
- 删除图纸（仅草稿状态可删除）

#### 4.3.2 画布
- 无限画布（可平移和缩放）
- 鼠标滚轮缩放，中键拖拽平移
- 网格背景（辅助对齐）
- 支持撤销/重做

#### 4.3.3 元件放置
- 左侧元件库面板，展示所有已保存的元件（按分类分组、可搜索）
- 从元件库拖拽元件到画布上放置
- 每次放置创建一个独立的元件实例（可设置实例标签，如 CB1、T1）
- 实例支持旋转（0°/90°/180°/270°）
- 实例支持拖拽移动

#### 4.3.4 连线
- 连线工具：点击一个实例的引脚，拖拽到另一个实例的引脚，创建连线
- 连线采用正交折线路径（水平+垂直线段）
- 连线自动路由，支持手动调整路径
- 连线可选中、删除
- 移动实例时，已连接的连线端点自动跟随更新

#### 4.3.5 选择与编辑
- 单击选中实例或连线
- Shift+单击多选
- 空白区域拖拽框选
- 选中后可移动、删除（Delete 键）
- 右键菜单：旋转、删除、查看/编辑属性
- 属性面板：显示选中实例的详细信息（标签、类型、引脚连接情况等）

#### 4.3.6 提交审核
- 配网图编辑者完成编辑后，点击"提交审核"按钮
- 系统将当前版本标记为"待审核"状态
- 提交后编辑者可继续编辑（产生新版本），但已提交版本不可修改

### 4.4 审核模块

#### 4.4.1 审核队列
- 审核者登录后可看到所有待审核的提交列表
- 列表显示：图纸名称、提交者、提交时间、状态

#### 4.4.2 审核操作
- 打开待审核的图纸（只读模式预览）
- 审批通过：变更自动上线发布，查看者可立即看到
- 审批驳回：需填写驳回原因，编辑者可看到驳回信息并修改后重新提交
- 审核记录留存，可追溯

### 4.5 查看模块

#### 4.5.1 图纸浏览
- 查看者可浏览所有已发布的图纸列表
- 打开图纸后可平移、缩放查看
- 只读模式，不可编辑

#### 4.5.2 高级分析功能
- **停电模拟**：选择某个设备或线路段，模拟该点停电，分析影响范围（下游受影响的设备和区域）
- **潮流计算**：对当前图纸进行电力系统潮流计算，展示各节点的电压、功率分布等结果
- 分析结果以可视化方式展示在图纸上（如颜色标注受影响区域）

### 4.6 AI 智能助手模块

#### 4.6.1 对话交互
- 系统右侧提供 AI 对话面板
- 用户通过自然语言与 AI 助手交流
- AI 助手以流式方式实时返回响应
- 保留对话历史，支持多轮对话
- 对话上下文与当前打开的图纸关联

#### 4.6.2 AI 辅助绘图（面向配网图编辑者）
- **对话式绘图命令**：用户输入自然语言描述（如"在母线 B1 右侧放一个断路器 CB3，连到变压器 T2"），AI 自动在画布上执行对应的放置和连线操作
- **数据导入自动成图**：用户上传结构化数据文件（Excel/JSON），AI 解析数据内容，自动生成完整线路图布局
- **批量操作**：AI 可一次执行多个操作（如"按这条馈线数据，把所有设备都放上"）

#### 4.6.3 AI 信息查询（面向所有角色）
- **图纸信息问答**：用户询问图纸相关问题（如"这条馈线下面挂了几个变压器？"、"CB1 和 T1 之间经过了哪些设备？"），AI 分析图纸数据后回答
- **设备统计**：统计当前图纸中各类设备的数量、连接关系等
- **路径追踪**：查询两个设备之间的电气连接路径

#### 4.6.4 AI 触发高级分析
- 用户通过对话触发分析功能（如"帮我算一下这张图的潮流分布"、"模拟 CB1 跳闸后的停电范围"）
- AI 调用后端分析服务，将结果整理后返回给用户
- 结果同时在图纸上可视化展示

#### 4.6.5 AI 行为约束
- AI 对图纸的修改不会自动保存，仅在画布上实时预览
- 用户需要显式确认（点击保存）后，AI 的修改才会持久化
- 用户可以撤销 AI 的操作
- 破坏性操作（删除、清空）AI 需先向用户确认再执行

## 5. 非功能需求

### 5.1 安全性
- 用户密码加密存储（bcrypt）
- API 使用 JWT 令牌鉴权
- LLM API 密钥仅在服务端使用，不暴露给前端
- 所有敏感操作记录审计日志
- 角色权限在前端和后端双重校验

### 5.2 性能
- 图纸打开加载时间 < 3 秒（100 个元件实例以内）
- 画布操作（平移、缩放、拖拽）响应流畅，无明显卡顿
- AI 助手首字响应时间 < 2 秒（取决于 LLM 服务）
- 支持单张图纸至少 500 个元件实例

### 5.3 可用性
- Web 浏览器访问，无需安装客户端
- 支持主流浏览器（Chrome、Edge、Firefox 最新版）
- 界面文字使用中文
- 界面布局简洁直观，功能模块划分清晰

### 5.4 数据完整性
- 图纸版本化管理，每次保存生成新版本快照
- 历史版本不可修改，可追溯
- 元件库变更不影响已保存图纸中实例的显示（快照独立）
- 数据库定期备份

### 5.5 可扩展性
- AI 接入的 LLM 提供商可配置切换（OpenAI 兼容接口）
- 元件分类支持自定义扩展
- 后端 API 遵循 RESTful 规范，便于后续集成

## 6. 术语表

| 术语 | 说明 |
|------|------|
| 元件（Component） | 电气元件的符号定义，包含形状、引脚和内部连通矩阵 |
| 元件库（Component Library） | 所有已保存元件的集合，供配网图编辑器使用 |
| 元件实例（Instance） | 配网图中放置的一个元件副本，拥有独立的位置、旋转和标签 |
| 引脚（Pin） | 元件上的连接点，用于与其他元件建立连线 |
| 连线（Wire） | 配网图中两个元件实例引脚之间的外部连接线 |
| 连通矩阵（Connectivity Matrix） | 元件内部引脚之间的连接关系定义 |
| 图纸（Diagram） | 一张完整的 10kV 配电网线路图 |
| 图纸快照（Snapshot） | 图纸在某一时刻的完整状态（实例、连线、视口），用于版本管理 |
| 草稿（Draft） | 编辑者正在编辑、尚未提交审核的图纸状态 |
| 已发布（Published） | 通过审核后上线，对所有用户可见的图纸状态 |
| 潮流计算（Load Flow） | 电力系统分析，计算电网中各节点的电压和功率分布 |
| 停电模拟（Outage Simulation） | 模拟某处故障或检修停电，分析受影响的下游设备和区域 |
